# 전용건의 바이브코딩 포트폴리오

서울에서 활동하는 1994년생 전용건을 소개하는 한국어 반응형 포트폴리오입니다. `prompt.md`의 요구사항을 반영했습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 별도 설치 없이 실행되며, 편집 시에는 라이브 서버를 사용해도 됩니다.

## 구성

- `index.html`: 페이지 뼈대와 문의·상세 보기 대화상자
- `js/data.js`: 프로젝트, 서비스, 작업 노트, 사진 주소
- `js/icons.js`: 공통 아이콘
- `js/app.js`: 탭, 프로젝트 슬라이드, 모바일 메뉴, 대화상자, 이미지 대체 처리
- `js/components/`: 헤더, 메인 배너, 소개, 프로젝트, 서비스, 작업 노트, 푸터의 개별 컴포넌트
- `css/globals.css`: 공통 색상과 한국어 글꼴
- `css/layout.css`: 공통 레이아웃
- `css/components/`: 각 컴포넌트의 개별 스타일
- `assets/workspace.svg`: 사진 연결 실패 시 표시하는 로컬 작업 공간 이미지

프로젝트·서비스·작업 노트는 데이터 파일에서, 소개 탭은 `js/components/about.js`에서 수정할 수 있습니다. 파일을 직접 열어도 실행되도록 일반 스크립트와 템플릿 함수를 사용했습니다.

## 콘텐츠 안내

이름·지역·출생 연도·직업은 사용자 제공 정보입니다. 제작 분야, 프로젝트 제안, 작업 방식, 작업 노트는 포트폴리오 구성용으로 작성했습니다. 프로젝트는 실제 수행 경력이 아닌 기획 예시임을 페이지와 상세 화면에 표시합니다. 실제 고객 후기나 확인되지 않은 경력 수치는 사용하지 않습니다.

문의 폼은 입력 검증과 확인 메시지를 제공하며, 실제 전송·저장은 하지 않습니다. 실제 이메일·연락처는 제공받지 않아 페이지에 임의로 넣지 않았습니다.
